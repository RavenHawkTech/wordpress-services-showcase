# RavenHawk Services Showcase

Neon RavenHawkTech service card grid plugin for WordPress Gutenberg blocks, services, collaborations, and affiliate cards.

This repository contains the RavenHawk Services Showcase plugin package, update manifest, screenshots, and repository documentation for RavenHawkTech.

## Current Version

**v2.0.3**

## Features

- Gutenberg Service Card Grid block
- Individual Service Card child blocks
- Desktop column controls
- Image, title, text, and button support per card
- Optional new-tab button behavior
- Global editable section title
- RavenHawkTech admin menu grouping
- Tabbed admin page with General Settings and Style / Colors
- Editable colors, grid gap, and card radius controls
- GitHub manifest-based update metadata

## Repository Structure

This repository tracks the plugin package instead of the extracted plugin source files.

```text
/
├─ README.md
├─ SECURITY.md
├─ COPYRIGHT.md
├─ gitignore.txt
├─ releases/
│  └─ ravenhawk-service-card-grid.zip
├─ screenshots/
│  └─ README.md
└─ updates/
   └─ ravenhawk-service-card-grid.json
```

The package contains the full WordPress plugin folder, including the plugin PHP file, block JavaScript, stylesheet, admin icon assets, and plugin metadata.

## Installation

1. In WordPress Admin, go to **Plugins → Add Plugin**.
2. Click **Upload Plugin**.
3. Choose the RavenHawk Services Showcase package.
4. Click **Install Now**.
5. Activate the plugin.
6. Open **RavenHawkTech → Service Card Grid** in WordPress Admin.
